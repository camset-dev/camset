# 12. A universal app

- **Date:** 2026-10
- **Status:** accepted
- **Rule:** The editor is for any owner of a supported camera: no filters, categories or features shaped to one owner's
  workflow.

## Context

The editor is meant for any owner of a supported camera.

## Decision

No filters, categories or features shaped to one owner's workflow.

## Consequences

Owner-specific views belong in local tools (the proof viewer), not in the editor.

# Decisions

Why things are done as they are: one record per decision, dated, in [Michael Nygard's form](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions). Each record states its decision as it stands; when a decision changes, its record is rewritten, with one line saying what it said before, and git keeps the history ([decision 1](0001-record-decisions-as-adrs.md)). The table gives each rule in one sentence, from its record's Rule line; the record says why.

# Decisions

Why things are done as they are: one record per decision, dated, in [Michael Nygard's form](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions). A changed decision gets a new record that supersedes the old one. The table gives each rule in one sentence, from its record's Rule line; the record says why.
